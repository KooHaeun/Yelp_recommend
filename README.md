# 추천 알고리즘 기초 구현 (MovieLens)

레스토랑 추천 연구를 시작하기 전에, 대표적인 추천 알고리즘을 MovieLens 데이터로 직접 구현해 본 학습용 저장소입니다.

## 구현 내용

| 방법 | 설명 |
| --- | --- |
| 콘텐츠 기반 필터링 | 장르 등 아이템 정보를 CountVectorizer·TF-IDF로 벡터화해 코사인 유사도로 추천 |
| 아이템 기반 협업 필터링(IB-CF) | 사용자-아이템 평점 행렬에서 아이템 간 유사도로 추천 |
| 행렬 분해(MF) | TruncatedSVD·SVD로 잠재 요인을 학습해 평점 예측 |
| 개인화 MF | 사용자별 예측 평점으로 상위 아이템 추천 |

## 이어진 연구

이 실습을 바탕으로 리뷰 텍스트(CNN)와 레스토랑 카테고리(임베딩)의 상호작용을 학습하는 딥러닝 추천 모델을 연구했고, 베이스라인 대비 MAE·RMSE를 30% 이상 줄였습니다.

- 구하은, 이청용, 김재경. (2023). 레스토랑 카테고리와 온라인 소비자 리뷰를 이용한 딥러닝 기반 레스토랑 추천 시스템 개발. *경영정보학연구*, 25(1), 27-46.

## 기술 스택

Python, pandas, scikit-learn, SciPy
